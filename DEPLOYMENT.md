# Розгортання та відновлення

Повна інструкція всього сервера: `../luxpower-automation/docs/server-restore.md`.
Клонуйте репозиторії поруч у `/home/maksym/projects/`; поточна інтеграція
використовує Python 3.13+, systemd і Codex CLI 0.167.2.

- Runtime — стандартна бібліотека Python; створіть нову `.venv` на новій ОС.
- На новій машині потрібний власний `codex login`. Автентифікація не входить у Git.
- `deploy/provision.py` готує приватну sandbox-політику та посилання на login.
- Для відновлення діалогів перенесіть узгоджену приватну копію
  `~/.local/share/codex-telegram/`, а не лише код.
- Бази користувачів містять діалоги, повідомлення й черги; не публікуйте їх.
- Незавершені staged-зміни лежать у `~/projects/codex-workspaces/`:
  збережіть їх окремо, перш ніж створювати робочі копії заново.
- Бот має запуститися першим і створити `state/codex-access.json`.
- Після завершення завдань код агента застосовується командою
  `systemctl --user restart codex-telegram-agent.service`.
- Зміна лише списків доступу не потребує перезапуску агента.
- Перезапуск не повторює завдання, що вже виконувалися. Файли могли бути
  частково змінені — перед повторним завданням перевірте результат.

Не послаблюйте sandbox-політику для обходу помилок перенесення шляхів.
